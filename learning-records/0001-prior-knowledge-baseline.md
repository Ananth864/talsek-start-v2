# Prior-knowledge baseline: React Router, no SSR meta-framework

Status: active

The user is comfortable-but-rusty with React + TypeScript, and knows React Router (client-side routing) but has no prior SSR / meta-framework experience. TanStack Start is their first. Evidence: self-reported in the session-1 intake.

Implications: lean on React-Router analogies for routing concepts; the **server/client execution boundary, SSR, and server functions are genuinely new** and must be taught explicitly rather than assumed. The success metric is **verification fluency** (read / spot / direct AI), not from-scratch recall — so lessons prioritise mental models and pattern recognition over syntax drills.
